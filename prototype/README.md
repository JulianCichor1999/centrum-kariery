# Centrum Dowodzenia — etap 3 (DEMO)

Najprościej: otwórz `index.html` w Edge lub Chrome. Prototyp działa też bez internetu. Skrypty i style są lokalne. Prywatne instrukcje użytkownika nie są częścią publicznego repozytorium.

Alternatywnie, z folderu projektu uruchom w PowerShell:

```powershell
node prototype/server.cjs
```

Następnie otwórz http://127.0.0.1:8765/prototype/. Ctrl+C zatrzymuje serwer. Potrzebny jest Node.js; serwer nie wymaga instalowania pakietów. Służy wyłącznie do wyświetlania plików i nasłuchuje lokalnie.

## Co sprawdzić

1. Dodaj przykładową ofertę, obejrzyj ją i utwórz aplikację.
2. Dodaj zadanie, rozmowę i notatkę w widoku aplikacji. Obejrzyj je również w Planie i wyszukiwarce.
3. Zmień status. „Wysłana” wymaga potwierdzenia; żadna wiadomość nie jest wysyłana.
4. W Materiałach dodaj opis wersji. W Dokumentach aplikacji przypnij tę wersję.
5. Otwórz CV MASTER AI i przejdź przez sześć kroków na danych aplikacji.

**Zmiany znikają po odświeżeniu.** To pamięć pojedynczej karty, nie baza danych. Firmy, oferty i zdarzenia są DEMO. Nie wprowadzaj poufnych danych. Nie wykonano integracji z modelami, pocztą, Drive ani portalami. Przypięte materiały to opisy, a nie wygenerowane pliki CV.
