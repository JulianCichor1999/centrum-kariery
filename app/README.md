# Centrum Kariery — aplikacja lokalna

Aktualna instrukcja instalacji i używania: [README projektu](../README.md).

- [Architektura i granice bezpieczeństwa](../docs/ARCHITECTURE.md)

Uruchomienie w terminalu po instalacji zależności: `python -m app.run`.
Adres aplikacji: http://127.0.0.1:8766/. Domyślny katalog danych w Windows: `%LOCALAPPDATA%\CentrumKariery`.

Szczegółowy podręcznik z lokalnymi ustaleniami użytkownika pozostaje poza publicznym repozytorium. Baza, CV, portfolio, tokeny i kopie nie są częścią kodu źródłowego.
